# MusicPocket 可行性分析报告

## 产品概述

MusicPocket 是一款将视频平台链接转换为离线音频的工具。用户粘贴 TikTok、抖音、B站、小红书的视频链接，系统自动提取音频并转换为 MP3 等格式，支持离线播放。

核心流程：**粘贴链接 → 转换 → 离线收听**

## 综合可行性判断

| 维度 | 可行性 | 说明 |
|------|--------|------|
| 做出可演示版本 | **高** | 技术栈成熟，2-3周可出 Demo |
| Android 独立安装包长期运行 | **中高** | 侧载分发无审核，但需持续维护解析器 |
| 国内应用商店正式上架 | **中低** | 版权和平台协议问题 |
| 苹果 App Store 上架 | **低** | 审核规则 5.2.3 几乎直接触发 |
| 长期稳定支持四个平台 | **中低** | 每个平台相当于一个需持续维护的模块 |
| 获得平台官方授权后运营 | **高** | 但获得授权本身非常困难 |

## 技术可行性

### 核心实现流程

```
粘贴分享链接
   ↓
识别平台并还原短链接
   ↓
解析视频页面，找到真实音视频地址
   ↓
下载视频或音频流
   ↓
提取音频、保存并离线播放
```

### 1. 链接识别（简单）

用户粘贴的文本可能是：
- 纯 URL：`https://v.douyin.com/xxxx/`
- 分享文本：`3.28 复制打开抖音，看看【某某的作品】 https://v.douyin.com/xxxx/`

需要：正则提取 URL → 判断平台 → 跟随短链接重定向 → 提取视频 ID

### 2. 获取真实媒体地址（核心难点）

**方案A：调用平台官方 API**
- 最稳定、最合规
- 但几乎没有平台提供"任意公开视频下载"的接口
- 仅限用户自己授权的内容

**方案B：解析网页和非公开接口（主流方案）**
- 模拟浏览器访问视频页面
- 分析网页源码或接口请求
- 获得临时播放地址
- 需持续维护：参数签名、Cookie校验、设备指纹、频率限制

**方案C：服务器模拟浏览器（兜底方案）**
- Playwright / Chromium 无头浏览器
- 兼容性最强，但资源消耗高
- 适合作为方案B失效时的备选

### 3. 音频转换（简单）

FFmpeg 一行命令：
```bash
ffmpeg -i input.mp4 -vn -c:a libmp3lame -b:a 192k output.mp3
```

支持 MP3/M4A/AAC/Opus，128/192/320 kbps，音量标准化。

## 四个平台技术难度

| 平台 | 技术难度 | 主要问题 |
|------|---------|---------|
| TikTok | 中 | 地区差异、签名参数（msToken/X-Bogus）、临时链接有效期短 |
| 抖音 | 中高 | 风控严格、Cookie校验、X-Bogus签名、频繁更新、验证码 |
| B站 | 中高 | DASH音视频分离（但可直取音频流）、wbi签名、高音质需大会员 |
| 小红书 | 高 | 反爬最强、X-s/X-t签名、设备指纹、登录态强制校验 |

每个平台应视为**独立维护的产品模块**，而非"一套代码支持四个平台"。

## 上架风险分析

### Apple App Store（风险最高）

审核规则 5.2.3 明确规定：
> 没有第三方内容来源的明确授权，App 不得保存、转换或下载第三方音视频

直接以"转换抖音/B站链接为MP3"为卖点，审核通过概率极低。

### Android

技术限制少，可通过官网 APK、企业分发、第三方市场发布。但主流应用商店仍可能因版权投诉下架。

## 合规改造建议

### 方案一：用户自有内容管理器（推荐）

只支持用户上传自己的视频、从相册导入、授权账号下自己发布的内容。

> "将自己的视频、课程录音和创作素材转换为离线音频。"

上架成功率最高。

### 方案二：播客和知识内容工具

粘贴链接后不下载原音频，而是提取字幕、生成 AI 摘要、做成知识卡片。核心价值从"下载"转为"内容整理"。

### 方案三：创作者合作平台

让创作者主动授权上传，粉丝可离线收听，收益分成。更像"视频创作者的音频分发平台"。

## 开发周期估算

以 MVP 为例（3-5人团队）：

| 工作 | 时间 |
|------|------|
| App 基础界面和播放器 | 2-3 周 |
| 链接识别和任务系统 | 1 周 |
| 单个平台解析器 | 1-3 周 |
| 四个平台初步适配 | 5-10 周 |
| 下载、转码、离线管理 | 2-3 周 |
| 测试及风控处理 | 2-4 周 |

总计约 **2-4 个月**可出较完整版本。

后续持续投入：解析器维护、服务器运维、风控应对、应用市场审核、版权处理。

## 最终建议

技术推荐：
> Flutter App + 后端插件式解析 + FFmpeg 本地/云端转码 + 本地离线播放器

产品推荐：
> 不以"全网视频转MP3"为卖点，转型为"用户自有视频转音频 + AI 摘要 + 私人知识音频库"

保留"粘贴、转换、离线收听"的核心体验，显著降低上架和版权风险。
